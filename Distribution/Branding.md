# FGOTrack branding

The production icon and in-app mark were generated with the imagegen skill in built-in tool mode, then exported at the required icon size with `sips`.

- In-app original: `FGOTrack/Assets.xcassets/BrandLogo.imageset/FGOTrack.png`
- Opaque 1024 × 1024 App Store icon: `FGOTrack/Assets.xcassets/AppIcon.appiconset/AppIcon.png`
- Palette: forest green, ivory and a mint transaction dot.

Exact generation prompt:

> Use case: logo-brand. Asset type: production iOS app icon for FGOTrack, an expense and budget tracker with personal and pooled house finances. Create one square 1024x1024 full-bleed opaque icon, flat vector-like finish. A bold simple ivory abstract F monogram composed of two parallel horizontal tracks and one vertical spine, with a single small mint circular node suggesting a tracked transaction. Deep forest green background matching a restrained premium finance app. Centered geometric mark occupying about 65% of width, generous even clear space. Crisp edges, clear at tiny sizes. No text or lettering beyond the abstract F symbol, no mockup, no phone frame, no outer rounded corners, no shadows, no gradients, no watermark. Save an image file for integrating into the Xcode asset catalog.
